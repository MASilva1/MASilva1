## 🚀 Proyectos destacados

### 🗓️ [Sala 13 — Sistema web de reservas institucionales](https://github.com/MASilva1/mi-primer-proyecto/tree/main/sala13-reservas-inteligentes)

**Google Apps Script · JavaScript · HTML/CSS · Google Calendar · Google Sheets**

Detecté un problema recurrente en la coordinación de una sala compartida: consultas individuales, cambios de horarios y riesgo de superposiciones. Diseñé e implementé una aplicación con calendario visual, validación de disponibilidad, reservas recurrentes y recordatorios.

- **Mi aporte:** relevamiento funcional, diseño del flujo, desarrollo asistido por IA e integración de servicios.
- **Resultado reportado:** reducción *estimada* cercana al **80 % del tiempo administrativo dedicado a coordinar reservas** durante los primeros meses de uso. No es una métrica auditada.
- **Evidencia:** caso de negocio, arquitectura y código fuente publicado.

[📂 Ver proyecto y documentación](https://github.com/MASilva1/mi-primer-proyecto/tree/main/sala13-reservas-inteligentes) · [🌐 Ver aplicación institucional](https://tinyurl.com/sala13idei)

### 🤖 [Gestión inteligente de solicitudes administrativas — SmartDesk AI](https://github.com/MASilva1/mi-primer-proyecto/tree/main/portfolio/idei-gestion-solicitudes-ia)

**n8n · OpenAI · Gmail · Airtable · Notion · Slack · HITL**

Prototipo académico basado en un caso de gestión administrativa: integra recepción y registro de solicitudes, consulta de conocimiento, clasificación asistida por IA y borradores de respuesta **sujetos a aprobación humana**.

- **Mi aporte:** diseño del proceso, orquestación de herramientas, control de errores y pruebas.
- **Evidencia:** workflow exportado y sanitizado, documentación, casos de prueba y video demostrativo.
- **Principio:** automatizar lo repetitivo sin quitar el control de las decisiones sensibles a las personas.

[📂 Ver caso técnico](https://github.com/MASilva1/mi-primer-proyecto/tree/main/portfolio/idei-gestion-solicitudes-ia) · [▶️ Ver demostración](https://youtu.be/qwjR3EYyDpg)
